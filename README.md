# School Fees Management System

A School Fees Management System developed using Java and MySQL. This project helps manage student information, fees records, and payment details efficiently.

## Technologies Used

- Java
- MySQL
- JDBC
- phpMyAdmin
- HTML
- CSS
- JavaScript

## Features

- Admin Login
- Student Management
- Fees Management
- Payment Management
- Database Integration
- Student Records Management

## Database

MySQL database is used to store student, fees, and payment information.

The database is managed using phpMyAdmin.

Database Name:

school_fees_db

## Database Tables

- admin
- students
- fees
- payments

## Project Structure

- `DBConnection.java` - Database connection
- `Main.java` - Main application file
- `school_fees_db.sql` - MySQL database file
- `index.html` - Web page
- `style.css` - Styling
- `app.js` - JavaScript functionality

## How to Run the Project

1. Install Java and MySQL.
2. Start MySQL using XAMPP.
3. Open phpMyAdmin.
4. Create a database named `school_fees_db`.
5. Import the `school_fees_db.sql` file into the database.
6. Configure the database connection in the Java project.
7. Run the project.
